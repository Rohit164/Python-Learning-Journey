1. del dict[key]
   → Deletes a specific key-value pair
   → Key missing = KeyError

2. dict.pop(key)
   → Deletes a specific key
   → Returns its value
   → Key missing = KeyError

3. dict.pop(key, default)
   → Deletes and returns value if key exists
   → Returns default if key doesn't exist
   → No error

4. dict.popitem()
   → Removes last inserted key-value pair
   → Returns (key, value) tuple
   → Empty dictionary = KeyError

5. dict.clear()
   → Removes all items
   → Dictionary still exists as {}

6. del dict
   → Deletes the entire dictionary variable
   → Using it afterward = NameError


7. 📝`keys()`

dictionary.keys()

* Returns all keys
* Returns a dict_keys view object
* The view is dynamic and reflects dictionary changes

If you want a normal list:

list(dictionary.keys())

* Creates a separate list of keys [key1, key2, ...]
* Doesn't automatically update when the dictionary changes



8. 📝`values()`

dictionary.values()

* Returns all values
* Returns a dict_values view object
* The view is dynamic and reflects dictionary changes

If you want a normal list:

list(dictionary.values())

* Creates a separate list of values [value1, value2, ...]
* Doesn't automatically update when the dictionary changes



9. 📝`items()`

dictionary.items()

* Returns all keys and values pairs
* Returns a dict_items view object
* The view is dynamic and reflects dictionary changes

If you want a normal list:

list(dictionary.items())

* Creates a separate list of items [(keys,values), ...]
* Doesn't automatically update when the dictionary changes

# Python Dictionary Views and Looping

## 1. `keys()` Method

The `keys()` method returns all keys present in a dictionary.

### Syntax

```python
dictionary.keys()
```

### Example

```python
student = {
    "name": "Rohit",
    "age": 21,
    "course": "Python"
}

print(student.keys())
```

### Output

```text
dict_keys(['name', 'age', 'course'])
```

### Important Points

* Returns only dictionary keys.
* Returns a `dict_keys` view object.
* The view is dynamic, meaning changes in the dictionary are reflected automatically.

Example:

```python
student = {
    "name": "Rohit",
    "age": 21
}

keys = student.keys()

student["city"] = "Mumbai"

print(keys)
```

Output:

```text
dict_keys(['name', 'age', 'city'])
```

### Convert Keys to List

```python
keys_list = list(student.keys())
```

This creates a separate list snapshot.

student = {

# 4. Dynamic Views vs List Snapshot

The following methods return dynamic views:

```python
dictionary.keys()
dictionary.values()
dictionary.items()
```

Dynamic means if the dictionary changes, the view also reflects the changes.

Example:

```python
employee = {
    "name": "Rohit",
    "salary": 50000
}

values = employee.values()

employee["city"] = "Mumbai"

print(values)
```

Output:

```text
dict_values(['Rohit', 50000, 'Mumbai'])
```

However:

```python
values_list = list(employee.values())
```

creates a separate list.

If the dictionary changes later, the list will not automatically change.

### Remember

```text
dictionary.keys()          → Dynamic View
dictionary.values()        → Dynamic View
dictionary.items()         → Dynamic View

list(dictionary.keys())    → Snapshot List
list(dictionary.values())  → Snapshot List
list(dictionary.items())   → Snapshot List
```

# 7. Looping Through Keys and Values Together

Use `items()` to access both keys and values.

### Syntax

```python
for key, value in dictionary.items():
    print(key, value)
```

### Example

```python
employee = {
    "name": "Rohit",
    "department": "IT",
    "salary": 65000

for key, value in employee.items():

```

Output:

```text
name -> Rohit
department -> IT
salary -> 65000
```

## Tuple Unpacking

`items()` returns:

```text
(key, value)
```

Python automatically unpacks them:

```python
for key, value in dictionary.items():
```

For example:

```text
("name", "Rohit")
   ↓        ↓
  key     value
```

# 12. Filtering + Counting + Total

A common real-world pattern is:

1. Filter records
2. Store matching records
3. Count them
4. Calculate total

### Example

```python
employees = {
    "Rohit": 65000,
    "Amit": 45000,
    "Rahul": 72000,
    "Sneha": 55000,
    "Priya": 90000,
    "Karan": 48000
}

eligible_employees = {}

count = 0
total = 0

for employee, salary in employees.items():

    if salary >= 50000:

        eligible_employees[employee] = salary

        count += 1

        total += salary

print(eligible_employees)

print(f"Total Eligible Employees = {count}")

print(f"Total Salary = {total}")
```

### Output

```text
{
    'Rohit': 65000,
    'Rahul': 72000,
    'Sneha': 55000,
    'Priya': 90000
}

Total Eligible Employees = 4

Total Salary = 282000
```

# ⭐ Most Important Dictionary Looping Patterns

## Pattern 1 — Keys

```python
for key in dictionary:
    print(key)
```

## Pattern 2 — Values

```python
for value in dictionary.values():
    print(value)
```

## Pattern 3 — Key + Value

```python
for key, value in dictionary.items():
    print(key, value)
```

## Pattern 4 — Filter Dictionary

```python
result = {}

for key, value in dictionary.items():
    if condition:
        result[key] = value
```

## Pattern 5 — Transform Dictionary

```python
result = {}

for key, value in dictionary.items():
    if condition:
        result[key] = "Something"
    else:
        result[key] = "Something Else"
```

## Pattern 6 — Filter + Count + Total

```python
result = {}
count = 0
total = 0

for key, value in dictionary.items():

    if condition:

        result[key] = value

        count += 1

        total += value
```
